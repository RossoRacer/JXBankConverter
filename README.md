# JX Bank Converter

Converts JX-8P banks of presets to banks that can be used in JX-10 and MKS-70, using bank GS-CUSTOM-A.syx as a validation reference.

## 📱 Features
- Feature 1 - Simple drag and drop interface.

## 🛠 Tech Stack
- **Language:** Swift / SwiftUI / UIKit
- **Architecture:** MVVM / MVC
- **Tools:** Xcode 16+

## 🚀 Getting Started

### Prerequisites
- Mac running macOS Sequoia (or latest)
- Xcode installed (version 16 or newer)
